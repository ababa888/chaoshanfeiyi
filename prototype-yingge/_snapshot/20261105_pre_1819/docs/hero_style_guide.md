# 踏鼓 · 水浒三好汉像素素材规范

适用对象：武松（行者 / 鼓手）、林冲（豹子头 / 矛兵）、李逵（黑旋风 / 盾兵）。
所有素材由 `tools/gen_assets.py` 程序化生成，重跑即可复现；本规范用于新增好汉或改稿时对齐画法。

---

## 1. 画布与安全边

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 动作帧基础画布 | **48 × 64 px** | 所有状态共用，脚底基线 `y = 60` |
| 动作帧导出 | **144 × 192 px** | 基础画布 **3× nearest**，基线导出为 `y = 180` |
| 定妆照画布 | **256 × 256 px** | 1× 导出，不缩放 |
| 标注带 | 底部 **24 px**（y = 232–255） | 深底 + 2px 金线，文字不越界 |
| 安全边 | 左右 **4 px**、顶部 **3 px**、底部（基线以下）**4 px** | 武器可贴边，但不得裁断轮廓 |
| 最小可读块 | 1 px（导出 3 px） | 禁止小于 1px 的碎线、禁止抖动噪点 |

- 动作帧：角色脚底始终落在 `y = 60`（导出 180）。跳跃/受击只允许整体上下位移，落地帧必须回到基线。
- 定妆照：全身入画（头顶到靴底），人物占画布高度约 **210–224 px**，左右留出武器空间。
- 定妆照为**正面略侧 3/4**（头、肩、脚尖都略朝画面右侧），武器与披挂在身体两侧展开，不交叉挡脸。

## 2. 调色板（28 → 40 色）

基础 28 色沿用既有环境/角色色，不删不改：

```
ink #120e14  night #1e162c  deep_red #761a22  red #b82c28  vermilion #e8502e
gold #eeba58  amber #ffd87a  cream #fff0ce  skin #eec494  skin_dark #c28e66
teal #24625e  jade #5cb28a  purple #5c408a  violet #9a6cbc  blue #3a5ea0
steel #7a8a9c  brown #744c34  leather #a67648  grass #4a6e3a  white #ffffff
sky_low #2e223e  sea #2a344c  mist #60607a  wall #3e2e3a  tile #261e2c
window #d68a4e  fg #0e0a10  fg_green #223024
```

好汉三阶明暗新增 **12 色**（总计 **40 色**，manifest `palette_count = 40`）：

| 键 | Hex | 用途 |
| --- | --- | --- |
| `shadow` | `#0a080e` | 统一轮廓与地面投影 |
| `gold_dark` | `#a2702c` | 金饰暗部 |
| `gold_light` | `#ffe8aa` | 金饰高光 |
| `skin_light` | `#fcdab4` | 皮肤高光 |
| `skin_shadow` | `#926048` | 皮肤暗部 |
| `red_dark` | `#58121a` | 赤面 / 红衣暗部 |
| `red_light` | `#ec7654` | 赤面 / 红衣高光 |
| `teal_dark` | `#12443a` | 青甲暗部 |
| `teal_light` | `#84c8a4` | 青甲高光 |
| `violet_dark` | `#38225a` | 紫甲暗部 |
| `violet_light` | `#c6a0e0` | 紫甲高光 |
| `steel_dark` | `#485262` | 铁器 / 斧刃暗部 |

取色规则：每块材质只用 **暗 / 中 / 亮** 三档；中间调必须是上表已有色，暗亮两档只能从新增 12 色或同族深/浅色里挑，不得临时混出新色。

## 3. 明暗与光照

- **唯一光源：左上方（方位角约 135°，俯角约 45°）**。三位好汉、所有帧、所有定妆照同一套规则。
- **三阶硬边**：
  - 中间调：材质本色铺满；
  - 亮阶：朝左上的边/面，宽 1 px（导出 3 px）；
  - 暗阶：朝右下的边/面，宽 1–2 px（导出 3–6 px）。
- **轮廓**：所有外轮廓先用 `shadow` 描 **2 px**（导出 6 px），再填材质；不描边会与深色背景粘连。
- **投影**：定妆照在脚下偏右下画椭圆软影？不允许半透明渐变，改为 **纯色 `shadow` 硬边椭圆**，向右下偏移 10–14 px；动作帧投影由引擎绘制，素材本身不带投影。
- **禁止**：抗锯齿边缘、半透明渐变、发光叠加、抖动（dither）噪点、非整数像素位移。
- 过渡只允许**整块色阶跳变**（例如红面从 `red_dark` → `red` → `red_light`），不做渐变过渡带。

## 4. 脸谱谱式

| 好汉 | 基调 | 眉眼 | 额纹 / 头饰 | 髯口 | 盔缨 |
| --- | --- | --- | --- | --- | --- |
| 武松 | 赤面 | 黑眼窝 + 金睛，眉峰上扬 | 金箍压额，额心火纹 | 黑髯三绺，垂至胸口 | 赤红短缨，向后甩 |
| 林冲 | 白面豹纹 | 黑眼窝 + 白底眼，眼尾上挑 | 金盔压额，额侧豹斑 | 短黑髯，收在下颌 | 红缨 + 金盔顶 |
| 李逵 | 黑面 | 琥珀环眼（金圈黑瞳），眉骨粗 | 红巾缠额，金巾扣 | 大黑髯，盖住嘴与下颌 | 红巾尾，向左上飘 |

- 定妆照必须能数清：**眉 2 条、眼 2 只、额纹/箍 1 组、髯口 1 组、盔缨 1 束**。
- 动作帧头部按 16 × 17 px 简化，但保留眼、眉、髯、缨四要素，保证缩小后仍可辨认。

## 5. 动作帧规格（每人 22 帧）

| 状态 | 帧数 | 单帧时长 (ms) | 峰值帧 | 循环 | 可否取消 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `idle` | 4 | 520 ×4 | – | loop | 是 | 呼吸起伏 + 披挂微晃；4 帧一循环约 2.08s |
| `march` | 6 | 140/140/150/150/140/140 | – | loop | 是 | 两拍一循环；第 1 拍 0–2 帧，第 2 拍 3–5 帧，落脚对齐鼓点；含 2 帧过渡 |
| `attack` | 4 | 90/110/130/150 | **2** | once | 否 | 起手 / 蓄力 / 峰值 / 收势 |
| `hurt` | 2 | 120/220 | – | once | 否 | 后仰（`hurt_0`）+ 回弹（`hurt_1`） |
| `down` | 2 | 200/800 | – | hold | 否 | 倒下（`down_0`）+ 落地尘（`down_1` 保持） |
| `skill` | 4 | 100/130/140/180 | **2** | once | 否 | 每人独有，峰值帧展示武器轨迹的收束点 |

- **峰值帧 = 索引 2**（第 3 帧）。引擎 `HERO_PEAK_PROGRESS = 0.42` 对应攻击总时长 480ms 的第 201.6ms，正好进入索引 2。
- 峰值帧触发：命中瞬间放大 1.4×、金色底环、冲击环、技能名、`counter` 重音；逻辑保留，仅缩放基准改为好汉专用 `HERO_SPRITE_SCALE`。
- 技能轨迹必须画出**起止点**：
  - 武松「双抛槌」：双槌从腰侧（起）抛到头顶两侧（止），峰值帧两槌在 `x0 ± 16, y ≈ 3`；
  - 林冲「回马枪」：枪尾从右腰（起）穿向左下（止），峰值帧枪尖在 `(x0 − 17, hip + 7)`；
  - 李逵「旋风劈」：双斧从头顶（起）横扫到腰侧（止），峰值帧斧头在 `x0 ± 16, hip − 1`。

## 6. 脚底基线与武器锚点

- **脚底基线**：动作帧 `y = 60`（导出 180）。所有状态（含倒地）都以此线为准；倒地帧横躺但脚仍在基线附近。
- **胯线** `hip = 38`，**肩线** `shoulder = 18`，**头心** `(x0, 15)`，`x0 = 24`（画布水平中心）。
- **手部锚点**：左手 `(x0 − 8, hip − 6)`，右手 `(x0 + 8, hip − 6)`；攻击/技能帧允许手腕前伸最多 10 px。
- **武器尺寸上限**：
  - 双槌：槌头半径 `r = 5`（导出 15 px），含尖刺不超过 `r + 3`；
  - 长枪：杆长 ≤ 44 px，枪头 6–8 px，红缨 4 px；
  - 双斧：柄长 ≤ 22 px，斧刃宽 ≤ 10 px。
- **武器不得**：切断出画、遮挡双方眼睛、穿过躯干中轴；允许在峰值帧短暂交叉，但必须能看出起止方向。
- **盾**：李逵的盾固定画在**躯干之后、左肩外侧**（`x0 − 11, shoulder + 5`，半径 6），只露半面，不挡双斧。

## 7. 命名、导出与交付

```
assets_gen/sprites/<hero>/<hero>_<state>_<idx>.png    # 144×192，idx 从 0 起
assets_gen/sprites/<hero>/<hero>_sheet.png            # 精灵表
assets_gen/sprites/<hero>/<hero>_preview.gif          # 预览 GIF
assets_gen/portraits/<hero>.png                       # 256×256 定妆照
assets_gen/portraits/lineup.png                       # 三位横排
config/hero_frames.json                               # 帧序表
```

- 精灵表：22 格横排，格 **144 × 192**，格间距 **4 px**，外边距 **8 px**，顶部 **14 px**（状态名），底部 **14 px**（帧号 00–21，与文件名 `_idx` 对齐），成品 **3268 × 228**；格线用 `steel_dark`。
- 预览 GIF：`idle 0–3`（900ms/帧）+ `march 0–5`（450ms/帧）+ `attack 0–3`（550ms/帧），共 **14 帧 / 8.5s**，144 × 192，无限循环。
- 帧序表 `hero_frames.json` 必须写全：`count / durations_ms / peak / loop / cancelable`，并记录 `portrait / sheet / preview / tagline`。
- **游戏内缩放**：`HERO_SPRITE_SCALE = 0.625`（0.625 × 2× 呈现 → 屏幕上约 180 × 240，身高与旧 32×40 素材一致）；其他角色仍用 `SPRITE_SCALE = 0.75`。
- 定妆照标注带：中文 1-bit 位图（无抗锯齿、无半透明），英文自绘 **5 × 7** 字；单行英文不超过 **42 字符**（含空格，字距 1 px）。
- 角色小图标：从定妆照裁 **96 × 96** 头部区域（`x 86, y 28`）再 nearest 缩到 **24 × 24**，禁止平滑缩放。

## 8. 已知边界与取舍

- **chibi 比例**：动作帧约 3.3 头身、定妆照约 3.6 头身，优先保证 48×64 / 256×256 内的可读性，不追求真实身高比。
- **正面略侧**：动作帧头部接近正面，靠武器左右分布表达朝向；不做左右翻转的第二套。
- **中文标注**：为保证 10–11 px 可读，采用运行时 1-bit 阈值化位图（关闭抗锯齿与半透明），字形来自系统字体栅格；英文与数字全部为内嵌 5×7 位图字。换到缺少中文字形的系统时，中文标注可能显示为方框。
- **无骨骼/无旋转**：动作帧是逐帧硬画，不做补间、不做骨骼旋转；引擎只做整图位移、倾斜与缩放。
- **调色板**：新增 12 色已写入 `manifest.json` 的 `palette_added`；后续如需再加色，必须同步更新本规范与自测。
