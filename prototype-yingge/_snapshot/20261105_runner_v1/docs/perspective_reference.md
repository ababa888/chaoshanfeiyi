# 斜俯视参考：可工程化观察

**查证**
- DB4405/T 315—2025：双列队形（两列平行对称前流）是最基础巡游队形；另有长蛇、双龙、八卦内外圈等基础队形。
- 街巷巡游受宽度限制，多以两列为主；广场表演才展开四列、圆圈、八卦等大阵。
- 96 人开幕式编队：大梯形势推进 → 散点八边形 → 龙舟队形。
- 摄影实践：低角度仰拍显宏伟，高机位/航拍显阵势；中景最易读到脸谱、槌花与肩背层叠。

**推断（本项目取用）**
- 纵队前后间距约 1.2–1.8 肩宽；斜俯视取 1.4–1.7 世界单位为一行距，保证前排不糊住后排脸。
- 斜上方 35°–45° 可见头顶、肩线、前臂与槌的投影，脸谱只露上半；故角色帧加宽肩、缩短腿。
- 旗帜/绸带沿前进方向（u 轴）拖尾，v 轴只做小摆；阴影统一指向左下。
- 为可读性把“两列”夸张到 v=±2.2–3.0（双龙/猛虎），长蛇保持 v=0 单列纵深。

**边界**：伪 3D 无透视收敛，远处人物不缩小，纵深只靠 v 排序、遮挡、落点 y 与阴影表达。
